# Разбор упражнения 1.12

Для `n=3` linear recursive sum создаёт цепочку состояний примерно `sum(3) -> sum(2) -> sum(1) -> sum(0)` и затем сворачивает результат назад. Work `O(n)`, stack depth `O(n)`.

Для merge sort `n=8`: размеры `8 -> 4 -> 2 -> 1`, то есть около `log2(8)=3` уровней splitting до leaves. Суммарная работа merge на каждом полном уровне порядка `n`, поэтому возникает `O(n log n)`.
