# Разбор 3.1

```text
0xA7   = 1010 0111
0x1234 = 0001 0010 0011 0100
```

8-bit two's complement:

```text
-1   11111111
-2   11111110
127  01111111
-128 10000000
```

Для byte inspection можно адресовать объект через `unsigned char *` и вывести `sizeof(x)` bytes. На x86-64 Linux ожидается little-endian, но упражнение требует наблюдения, а не догадки.
