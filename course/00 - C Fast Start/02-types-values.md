## Проблема

В Python можно написать:

```python
x = 10
x = "ten"
```

В C compiler должен заранее понимать, какие операции допустимы для конкретного значения и как с ним работать.

## Интуиция

Мы даём переменной не только имя, но и **тип (type)** — договор о том, какой вид значения в ней хранится и какие операции ожидаются.

```c
int count = 10;
double ratio = 0.5;
char grade = 'A';
```

Пока не пытайся вывести из типов точное количество байтов на любой машине. Это отдельная тема representation в Module 3.

## Объявление и изменение

```c
int count = 10;
count = 11;
```

Первая строка создаёт переменную и задаёт начальное значение. Вторая меняет значение уже существующей переменной.

## Целые и дробные операции

```c
int a = 5;
int b = 2;
int q = a / b;       /* 2 */

double x = 5.0;
double y = 2.0;
double r = x / y;    /* 2.5 */
```

Типы влияют на смысл операции. `5 / 2` для целых не хранит дробную часть.

## `const`: значение, которое этот код не должен менять

Если после инициализации изменение было бы ошибкой дизайна:

```c
const int max_attempts = 3;
```

`const` не означает «вечная глобальная константа». Для нас сейчас это локальный контракт: не менять через это имя.

## Преобразования

Иногда один numeric type преобразуется в другой. Делай важное преобразование видимым:

```c
int done = 3;
int total = 4;
double fraction = (double)done / total;
```

Здесь cast `(double)` нужен, чтобы деление не произошло как integer division.

Глубокие правила integer conversions и overflow появятся тогда, когда они начнут влиять на memory sizes и binary formats.

## Неправильная mental model

> «Тип — это просто подпись для читателя».

Нет. Compiler использует type, чтобы выбирать допустимые операции и диагностировать часть ошибок.

## Практика

Напиши программу, которая хранит:

- количество завершённых задач как `int`;
- общее количество как `int`;
- вычисляет долю как `double`;
- печатает оба исходных значения и результат.

Сначала предскажи, что получится без cast, затем проверь.
