# Isolation Lab — Acceptance

- demonstrates at least UTS + one of PID/mount namespace;
- process lifecycle clean;
- namespace IDs inspected before/inside/outside;
- cgroup v2 membership observed;
- resource limit experiment performed or environment limitation documented precisely;
- no random `sudo` as debugging strategy;
- cleanup of mounts/processes/resources;
- README says explicitly: not a secure production container runtime;
- isolation matrix complete;
- transfer observation/mechanism;
- debugging story for one permission/environment issue.
