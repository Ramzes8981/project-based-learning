# MiniKV v0 — Hints

Не читай весь файл заранее. Открывай следующий уровень только если действительно застрял.

## Hint 1 — representation

Сформулируй две сущности:

- одна запись key/value;
- контейнер нескольких записей.

Какие данные нужны каждой из них, чтобы отличать occupied от empty?

## Hint 2 — lookup

Не думай о hashing. Текущий алгоритм специально простой:

```text
для каждого occupied entry
    сравнить key text
    если совпал — вернуть найденную позицию/результат
```

## Hint 3 — update vs insert

`SET` удобно мысленно разбить на этапы:

```text
есть ли такой key?
   ├─ да -> update existing value
   └─ нет -> есть ли free slot?
              ├─ да -> insert
              └─ нет -> FULL
```

## Hint 4 — string capacity

Прежде чем копировать C string в fixed buffer, проверь, помещаются ли **символы плюс `\0`**.

## Hint 5 — design, не код

Если функция стала делать сразу поиск, валидацию, копирование, error formatting и печать — вероятно, responsibilities стоит разделить. Сначала разложи поведение на маленькие операции на бумаге.
