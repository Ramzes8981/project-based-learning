# Разбор упражнения 0.1

Открывай после собственной попытки.

Один из минимальных вариантов:

```c
#include <stdio.h>

int main(void)
{
    printf("build probe ok\n");
    return 0;
}
```

Сборка:

```bash
cc -std=c17 -Wall -Wextra -Wpedantic -g build_probe.c -o build_probe
```

Проверка:

```bash
./build_probe
echo $?
```

Ключевая часть упражнения — не этот код, а наблюдение за стадиями и warning.

Если при временной строке

```c
int unused = 42;
```

компилятор сообщил, что переменная не используется, значит warnings работают. Правильное исправление в этом упражнении — удалить ненужную переменную или использовать её по реальному назначению, а не глушить диагностику.
