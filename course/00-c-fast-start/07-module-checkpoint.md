## Explain

Без конспекта объясни:

1. Почему `main.c` не является исполняемым файлом?
2. Что compiler делает на нужном нам сейчас уровне модели?
3. Почему integer division отличается от floating-point division?
4. Почему массив из `N` элементов имеет допустимые индексы `0..N-1`?
5. Чем число используемых элементов отличается от размера фиксированного массива?
6. Почему C string требует конечный `\0`?
7. Как `struct` помогает не рассинхронизировать связанные поля?
8. Какая проблема появляется, когда implementation разбивается на несколько `.c`, и зачем после этого нужен linker?
9. Почему header change должен участвовать в build dependencies?

```text

```

## Transfer

Добавь **одну** новую операцию поведения без новых механизмов из Module 1. Например `COUNT` или вывод всех занятых записей.

## Gate

Не переходи к pointers, пока не можешь объяснить текущий проект без слов `stack`, `heap`, `ownership`, `hash`, `pointer`. Эти слова ещё не должны быть нужны для понимания Module 0.
