# Разбор упражнения Optional 1A

Для costs `c[i]` один возможный state: `dp[i]` — минимальная стоимость добраться до позиции `i` при точно заданной семантике оплаты позиции.

Типичная transition:

```text
dp[i] = cost(i) + min(dp[i-1], dp[i-2])
```

Но base cases зависят от того, оплачивается ли старт/финиш. Сначала зафиксируй контракт — именно поэтому курс требует формулу до кода.

Если нужны только два предыдущих значения, memory можно сократить с `O(n)` до `O(1)` после проверки корректности полной версии.
