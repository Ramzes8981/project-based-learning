# Разбор 1.1 — swap

```c
void swap_int(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
```

Контракт этого варианта: `a` и `b` должны адресовать живые `int` objects; `NULL` не поддерживается.

Если оба pointers указывают на один `x`, последовательность сохраняет то же значение: временно читается `x`, затем `x` присваивается самому себе и снова получает исходное значение из `tmp`.

Важно: функция не меняет сами pointer values у caller. Она меняет объекты, которые они адресуют.
