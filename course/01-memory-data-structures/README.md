# Module 1 — Memory, Pointers & Data Structures

**Цель:** понять память C достаточно глубоко, чтобы самостоятельно реализовать dynamic array и hash table без магии вокруг pointers/heap.

**Оценка:** ~55–70 часов.  
**Mini-milestone:** Dynamic Array / Vector.  
**Core milestone:** MiniKV → Hash Table in C.

## Prerequisites

Module 0 закрыт: fixed-array MiniKV работает, basic C syntax не съедает всё внимание.
