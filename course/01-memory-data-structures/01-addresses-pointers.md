## Проблема

В C аргументы функции передаются как значения. Поэтому это не работает так, как новичок часто ожидает:

```c
void set_zero(int x)
{
    x = 0;
}
```

После `set_zero(n)` переменная `n` у вызывающего кода не обязана измениться: функция получила собственное значение `x`.

Нам нужен способ сказать функции: «работай не с копией числа, а с **тем конкретным объектом**, который уже существует».

## Интуиция: место, где находится объект

Пока программа работает, её объекты где-то хранятся. У конкретного объекта есть место, по которому программа может к нему обратиться.

Числовое обозначение такого места называется **адресом (address)**.

Оператор `&` получает адрес объекта:

```c
int n = 7;
printf("%p\n", (void *)&n);
```

Само число адреса обычно не нужно человеку. Важен факт: теперь можно передать ссылку именно на `n`.

## Указатель

Переменная, значение которой является адресом объекта определённого типа, называется **указателем (pointer)**.

```c
int n = 7;
int *p = &n;
```

Ментальная модель:

```text
n: 7
^ 
|
p хранит способ найти n
```

`int *` читаем как «pointer to int».

## Разыменование

Если `p` указывает на допустимый `int`, выражение `*p` обращается к самому объекту:

```c
*p = 0;
```

Теперь функция может менять caller-owned object:

```c
void set_zero(int *value)
{
    *value = 0;
}

int main(void)
{
    int n = 7;
    set_zero(&n);
}
```

## `NULL`: сейчас объекта нет

Иногда pointer API должен уметь выразить «не указывает на объект». Для этого используется null pointer value, обычно записываемое `NULL`.

Разыменовывать `NULL` нельзя. Поэтому контракт функции должен говорить, допускается ли `NULL`.

```c
int set_zero_if_present(int *value)
{
    if (value == NULL) {
        return 0;
    }
    *value = 0;
    return 1;
}
```

## Pointer тоже передаётся по значению

Важный мост к будущему `realloc`:

```c
void redirect(int *p)
{
    int local = 10;
    p = &local;
}
```

Функция меняет свою копию `p`. Caller pointer сам по себе не перенаправляется.

Чтобы функция меняла pointer variable caller-а, позже понадобится pointer to pointer (`T **`). Не используй его до реальной необходимости.

## Неправильная mental model

> «Pointer — это сам объект».

Нет. Pointer — отдельное значение, которое позволяет найти другой объект. Несколько pointers могут вести к одному объекту; сам pointer тоже можно скопировать.

## Практика

Реализуй и проверь:

```c
int swap_ints(int *a, int *b);
```

Contract:

- если `a == NULL` или `b == NULL`, ничего не менять и вернуть `0`;
- иначе поменять значения местами и вернуть `1`.

Сначала нарисуй состояние `a`, `b` и двух caller variables до/после.

Разбор: [`01-addresses-pointers.solution.md`](01-addresses-pointers.solution.md).
