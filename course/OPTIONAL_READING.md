# Дополнительное чтение

Эти материалы **не обязательны** для прохождения курса. Вся необходимая теория должна находиться в собственных уроках репозитория.

Список существует потому, что некоторые книги и курсы дают полезную вторую перспективу или значительно более глубокое изложение.

## C и systems

- **Dive Into Systems** — сильное системное объяснение перехода от C к архитектуре, памяти, ОС и параллелизму.
- **CS50x** — хороший визуальный ввод в C, память, алгоритмы и структуры данных; русские переводы старых выпусков удобны как дополнительная подача.
- **Beej's Guide to C** — компактный справочник по C.

## Algorithms / discrete math

- **MIT 6.006 — Introduction to Algorithms** — углубление алгоритмов.
- **MIT Mathematics for Computer Science (6.042J)** — логика, доказательства, графы, комбинаторика, вероятность.

## Operating systems

- **Operating Systems: Three Easy Pieces (OSTEP)** — один из лучших учебных текстов по процессам, виртуальной памяти, concurrency и persistence.

## Architecture

- **Nand2Tetris** — прекрасный дополнительный project-driven путь от логических вентилей до CPU и assembler.

## Networking

- **Beej's Guide to Network Programming** — полезный справочник по socket API.

## Databases

- **Database Internals — Alex Petrov** — более глубокий взгляд на storage engines и distributed storage после базового DB-модуля.
- Официальная документация SQLite/PostgreSQL — для углубления конкретных механизмов.

## Rust

- **The Rust Programming Language** — хороший официальный учебник.
- **Rustonomicon** — advanced-материал по `unsafe` Rust; нужен существенно позже базового Rust bridge.

## Performance / architecture

- **Computer Systems: A Programmer's Perspective (CS:APP)** — сильная книга, если захочется ещё глубже связать код, ABI, память, linking и machine-level execution.

Курс может добавлять конкретные ссылки на эти материалы в тех уроках, где они особенно уместны.
