# Необязательные русскоязычные ресурсы

Курс больше **не зависит** от этих материалов. Вся обязательная теория находится в `course/`.

Этот файл нужен для ситуаций, когда хочется:

- посмотреть второе объяснение на русском;
- получить больше автоматических упражнений;
- посмотреть хорошую видеолекцию;
- глубже пройти тему в дороге.

Если внешний ресурс исчезнет, core course остаётся проходимым.

## C / CS intro

### CS50 на русском — Vert Dider / JavaRush

Сильная русская локализация старого CS50. Хороша как дополнительное визуальное объяснение C, памяти, algorithms/data structures.

- https://landing.javarush.com/ru/cs50/

Ограничение: перевод относится к старому выпуску курса, поэтому tooling/структура могут отличаться от актуальных материалов.

### Stepik — Основы программирования на C. Задачи

Полезен как дополнительный банк коротких упражнений по синтаксису/массивам/строкам.

- https://stepik.org/course/3078/

Не нужно проходить его целиком ради процента completion.

## Algorithms & Data Structures

### Computer Science Center / Stepik

Русскоязычные курсы CSC по алгоритмам и структурам данных подходят как дополнительная академическая практика.

- https://stepik.org/course/1547/
- https://stepik.org/course/217/

Внутренние уроки курса уже содержат обязательные Big-O, search/sort, trees/heaps, DP basics, hashing, graphs/BFS/DFS/Dijkstra.

## Tooling

### Missing Semester — русский community translation

Хорош как дополнительный материал по shell/Git/tooling. Переводы могут отставать от текущего оригинала.

- https://missing.csail.mit.edu/

## Operating Systems

Русскоязычные Stepik-курсы по ОС можно использовать для второй подачи scheduling/process/VM/concurrency concepts, но core theory уже находится в Modules 2/4/6.

## Networking

Русский Stepik «Основы компьютерных сетей» можно использовать как дополнительный packet/network lab companion:

- https://stepik.org/course/208904/

Core networking theory + socket/protocol/concurrency exercises находятся в Module 5.

## Database engineering

Русские курсы по СУБД полезны для production context SQL/schema/concurrency, но Module 7 самостоятельно объясняет filesystem/pager/pages/B+tree/transactions/WAL concepts.

## Правило

Внешний материал открывается только если он даёт дополнительную ценность. Никогда не откладывай следующий обязательный урок только потому, что не закончен companion-курс.
